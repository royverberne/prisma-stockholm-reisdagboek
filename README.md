# Studiereis Stockholm – Reisdagboek

Reisdagboek voor de Prisma Erasmus+ studiereis naar Stockholm (reis 2, 18–21 november 2026).

Eén zelfstandige pagina (`index.html`) zonder build-stap: leerdoelen, programma, kaart met scholen, dagboek, opbrengst en voor-en-na. Gegevens worden alleen in de browser van de gebruiker bewaard (localStorage); via "Back-up" in het tabblad *Voor & na* maak je een bestand.

## Publiceren
Statische site: Vercel serveert `index.html` rechtstreeks, geen instellingen nodig.
